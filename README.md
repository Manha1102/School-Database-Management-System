# Manha E-Solutions website (Vercel)
Static site. No build step.
1. Push this folder to GitHub (or drag it into vercel.com/new).
2. Framework preset: **Other**. Build command: empty. Output directory: `.`
3. Edit `config.js` for phone / WhatsApp / email.
4. The software lives at `/app/` (replace `app/index.html`).
